  depths stairs (44,6) -> map5 (3,30)

The route node (22,21) sits **inside the leash of BOTH the racks (leash 14,
6–7 tiles to the rack edge) and the cocoon (leash 10, 4–5 tiles to the cocoon
edge)**: a fight there means both packs are permanently in leash — swarm 8–10
reforms every 30 s. In every full leg the column arrives as a healthy stack,
the pile fight lasts 30–60 s, and 2–3 bots die (r8e4: 3 dead; r8f: 2 dead;
r8g: 3 dead). The column then loses the numbers it needs for the barrow ring
(~1900 hp, must be met 5-deep) and the font.

Candidate fixes for the next session (not yet tried — pick, or design better):

1. **Don't rest at the node — push the unbroken pass** (the original r4
   design): no quorum wait at (22,21) (quorum 0 / cap 0), the runner advances
   immediately on arrival, millers hold only point-blank. The column crosses
   the double-leash rect in ~10–15 s before the pile can form; respawns
   (30 s) can't keep pace. Risk: the pile still forms if the stack is slow.
2. **Move the node** off the double-leash overlap (e.g. (28,21), east of the
   racks, still west of the cantor's aggro) so the pile forms in single-aggro
   territory. Verify any new node against both aggro6 rects and the leash 14.
3. **Fix focus so the 5-deep actually focuses:** all five mark "lowest-HP
   aggroed" from their own (stale, per-peer) views, so marks disagree and DPS
   dilutes 2–3×. A distance-based mark (nearest aggroed target) aligns every
   bot at the same stack position to the same target.
4. **Kill the pile before the fight:** the runner pre-marks and the stack
   kites the racks edge-on so ghouls engage one-at-a-time instead of
   swarming the node.
5. Accept the attrition: the party arrives at the barrow 3-deep and the
   verdict is "the gauntlet attrition is the wall, not the boss" — a valid
   finding IF the font is still reached (needs the 3 survivors to beat the
   ring, ~1900 hp at ~70 dps = 27 s — marginal).

Also open (lower priority): the miller ±1–2 tile oscillation (catch-up path
overshoots the runner; the mill branch sends no stop) — cosmetic until a leg
needs the last 10 % of coherence.

**Trace fields** (`[trace] name t=(x,y) map= ret= rest= route= camp=(x,y)
nd= hp= bestD= swarm= nearTown= fr=(x,y) q= qT0=`): `ret` = retreating;
`route` = routeIdx; `camp` = current route node; `nd` = Chebyshev distance to
it; `bestD` = marked target distance (100 = none); `swarm` = aggressive mobs
in range; `fr` = the elected front runner as THIS bot sees it; `q` = quorum
within 6 of camp; `qT0` = quorum-wait start (0 = not waiting).

**Route tables (raider):** map 1: (32,16,3 s)/(14,14,3 s)/(10,10, portal →
hatch). map 3: (1,22,3 s)/(22,21)/(32,18)/(39,12)/(44,6, portal → depths).
map 5: (22,3) — the font (fight camp). map 2: (0,14, portal).

**Journal forensics** (`logs/m3_gate.bwj`, header `v 20`): `l` = login record
(name, tile, level, stats, inv blob), `k` = kit pick, `c <tick> <player>
<cmdType> <a> <b>` = command (type 0 = InputPath goal a,b — the ONLY way to
see what the walkers were actually sent), `h <tick> <hash>` = world hash every
100 ticks. `grep -a '^c ' logs/m3_gate.bwj | awk '$4==0'` lists all path goals.
