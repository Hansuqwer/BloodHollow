## 2. The bot (what actually works, as of r16b)

`tools/bots/main.cpp` — profile `raider`, five bots `m3g__00..04`,
auto-party on login. Key machinery (line numbers drift; search the anchors):

- `raiderRoute` (~252): node tables. map 1: (32,16) town rest / (14,14) /
  (10,10 hatch portal). map 3: (1,22) camp rest / (22,21) pile / (32,18)
  pre-depths / (39,12) / (44,6 depths portal). map 5: (22,3) font fight camp.
- `frontRunnerOf` (~196): one-brain election. **Direction-aware extremum:**
  min-x on map 1 (the town→hatch return march goes WEST), max-x on 3/5;
  dead-band 2; smallest id tie-break. Consensus-safe (two-pass).
- Column glue (~1847, maps 1/3/5): the runner runs the route machine;
  everyone else mills within 3 of the runner or paths back. Runner role
  adoption re-adopts the nearest node once (`wasRunner` flag).
- Route machine (~1895): walk node, rest, advance. Waypoint quorum holds
  (3+ within 6, 45 s cap) on maps 3/5 **except the pile node (22,21) which is
  wait-immune** (r9/r12). Depths portal settles only when the ring is clear
  (60 s cap). Map-1 hatch crosses as a stack: wait for q≥3, after 45 s cap
  cross if q≥3 else fall back to town (r13 D2 — suspect, see §5).
- Desync re-adoption (~835, r16b): if far (>8) from the current camp AND
  standing within 2 of a route node that is NOT the node just left, adopt it.
  Fixes retreat-drop routeIdx desync without fighting the advance.
- Combat posture (r9's): runner chases marks (`holdStack` exempts only the
  runner), millers hold their slots, march-first fall-through `bestD > 1` on
  maps 1/3/5, point-blank stop-and-win.
- Retreat (r8f/r8g): stack-retreat on map 3 pulls to the nearest un-fired
  party member; map 1 retreats to town; releases at 65%/85% + unchased or
  45 s cap.

## 4. Failure modes — do NOT retry these

1. **Unbroken march (r13 D3).** Dropping the intermediate quorum waits
   out-sprints the kills; the racks are never culled, the whole double-leash
   field converges on the first stop (swarm 10 at (32,18)), party wipes in
   ~25 s. r9 reached the font WITH the holds.
2. **Per-tick desync re-adoption (r16 first version).** The route machine
   advances k→k+1 while the walker still stands on node k; a nearest-node
   re-adoption on `dist-to-camp > 8` snaps routeIdx straight back — infinite
   loop, zero commands, 900 s frozen at staging. The r16b guards
   (stand-on-node ≤2, never node k-1) are mandatory.
3. **Max-x election on map 1 (pre-r16).** The return march goes west; max-x
   elected the rearmost bot, the column anchored on its own tail and
   ping-ponged in sight of town (every r13/r14/r15 leg).
4. **In-game kit oath at L13** — rejected by `World::kitChoose()`; seed
   class_id instead.
5. **`tmj` spawner extraction** returns only a subset of map-3 mobs; not the
   authoritative spawn table.
6. **`get_process_output` "completed"** can be stale/false — confirm leg end
   via `PERSIST_OK` + `[raid]` lines + server-process absence.
