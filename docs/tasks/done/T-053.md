# T-053 class kits foundation — DONE S14 (2026-09-05)

## Context

GDD §3 locks three kits: **Ravager** (melee, STR), **Gravecaller** (ranged
burst, INT), **Cultist** (support: heals/buffs/pet, VIT/INT→MAG/CHA). Sprint
14 lands the *plumbing* so kit content can iterate card-by-card afterwards.
The support-class design rule is the acceptance bar: party XP share counts
healing at 100% weight (already true — XP share is per-kill, healers stand in
the radius), and a party WITH a Cultist must out-survive one without.

## Scope

- `Entity::classId` (0 = unsworn, 1 = Ravager, 2 = Gravecaller, 3 = Cultist).
- Persistence v7: `characters.class_id INT DEFAULT 1`; existing characters
  and all fresh spawns default Ravager (zero compat break for campaign bots).
- Kit table `shared/content/kits.h`: per-kit stat seed at creation
  (str/vit/dex/intg/mag), skill-list gating, per-kit flavor name
  (Pale Choir lives in the fiction: Cultist display = "Pale Choir").
- `/kit ravager|gravecaller|cultist` slash verb: one-time choice, only while
  unsworn (classId 0) **or** at level 1 (early re-dedication); journaled as
  new Command kind `kKitChoose` (a = kit id — id-resolved like parties).
- Skill dispatch: `trySkill` routes channel → kit table instead of hardcoded
  `skill == 1`. Channels: 1 Power Swing (Ravager), 2 Mend, 3 Bless,
  4 Ironskin, 5 Firebolt.
- MP: `Entity::mp/mpMax`; maxMp = 30 + 6·(level−1); regen 1 per 20 ticks;
  `OwnStats` grows `classId u8`, `mp u32`, `mpMax u32`, `blessTicksLeft u16`,
  `ironskinTicksLeft u16` (protocol v238). `intg`/`mag` fields on the wire
  finally carry kit seed values instead of 0.

## Acceptance criteria

- Old DBs migrate (v6 → v7 ALTER, default 1); existing characters power-swing
  exactly as before (Ravager default = behavior freeze).
- `/kit` twice → rejected second time; at level ≥2 while sworn → rejected.
- dispatch table: unknown channel / wrong kit → silent no-op (era: "you lack
  the rite"), no spammy hard-fail text in the world event feed.
- Suite green, replay of an S13 journal still bit-exact (classId is spawn
  state threaded through the login record).

## Tests required

kit choice one-time + level gate; seed stats applied at spawn per kit;
channel-to-kit gating matrix; mp regen/cost math; replay-parity case.
