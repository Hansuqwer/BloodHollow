# T-034 balancer v2: gear-aware duel harness — DONE S12 (2026-09-05)

## Delivered

- `tools/duel/` → `bh_duel`: offline deterministic duel harness linking
  `bh_server_world` directly (zero network). Builds an in-memory arena World,
  spawns one content-table mob + one player with an explicit loadout, runs the
  real sim (`world.tick()`), reports win-rate, TTK median/p90, end-hp fraction
  across seeded reps (world rng reseeded per rep).
- Loadout knobs: `--level` (real XP curve + stat-point plan str|vit|dex|mix),
  `--weapon/--armor/--aura` (0..5, real debugGive + toggleEquip + InvSlot.aura),
  `--skill` (Power Swing weave), `--vials` (auto-sip at ≤50%), `--build`.
- `--table`: era sweep — all 8 mobs × player levels {L-1, L, L+2} × 6-step gear
  track (fists → shank → blade → +armor+aura I → +weave+vials → bone plate
  aura IV). Full 126-row table in **0.23 s wall** — soak-free Monte Carlo.
- `--selftest`: same seed twice ⇒ identical win/ticks/hp/end `worldHash`;
  **wired into CTest** (`bh_duel_selftest`) as a permanent determinism gate.
- Baseline artifact: `logs/duel-table-s12.csv`.

Assertions the curve relies on, now cheaply checkable any time:
1. fists→blade gradient ≈ 2× TTK reduction on-level (Ghoul: 8.1→4.0 s ✓).
2. Sustain (weave+vials) converts losing walls into wins without making
   trash free (Gnoll endhp 0.63).
3. +2-level mobs stay punitive on bare kit (all 0/9 rows) and beatable on
   veteran kit.
