# T-055 choir bot + dual-kit gate leg — DONE S14 (2026-09-05, mixed verdict)

## Context

The S13 two-fighter leg gave the benchmark: both Ravagers L5 at 556/583 s,
36 deaths, replay bit-exact. The Cultist design rule needs evidence the other
way: a **Ravager + Cultist** pair must out-survive / out-pace it (or at least
match pace with far fewer deaths — deaths are the XP tax).

## Scope

- `tools/bots`: parse `PartyReset/PartyMember` (roster mirror) on top of the
  existing own-stats parse.
- Campaign profile pairing change: after the S13 auto-party forms, the
  odd-indexed bot takes `/kit cultist` at level 1 (even stays Ravager).
  Choir behaviors (only when classId is Cultist per OwnStats):
  - at/after L3: Bless the party leader when entering a camp (and refresh);
  - any roster/visible party member (or self) below 60% hp → Mend them when
    off-cooldown and in range (chase to within healing range if needed);
  - still attacks mobs otherwise (Cultist can swing; pits give XP share).
- Gate leg `tools/s14_kit_leg.sh`: fresh DB, 2 bots, target L5, 600 s,
  journal + replay, same conventions as s13_party_leg.sh.

## Acceptance criteria

- Pair forms, odd bot swears to the Choir, blesses/mends land (server-side
  buff stamps + heal floaters; journal contains kSkill channels 2/3).
- Replay bit-exact (0 mismatches).
- Death count materially lower than S13's 36 at comparable progress; evidence
  table recorded in devlog 0015 (pace L2..L5, deaths, pots, kills).


## Evidence (mixed verdict — engineering gates pass, design claim: mixed)

- Formation race-proofed (welcome-gated invite + 10 s retry until roster≥2);
  oath journaled (kind 21); 77 Mends + 3 Blesses on the ledger.
- Deaths 38 vs baseline 36 — cultist heal cadence did not out-survive ghoul
  burst; early-band pace better (L3 92/145 s vs 179/226 s), late leg drags
  (~cultist swing −17%). See devlog 0015 for the lever list (Chorus /
  Mass Mend / Haste / T-034b camp tuning).
- Replay bit-exact (114 hashes, 0 mismatches).
