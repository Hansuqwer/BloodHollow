# T-097 — Named elites: options paper, nothing built (DESIGN)

## Context
GDD §9: named elites on 15–60 min random timers, world-announced first-kill — Old Maw (fields), Red Widow (mine), Cantor Vex (crypt). No stats, no timers, no spawners exist. Staff drafts options from shipped precedents; director designs. No code, no tests, no epoch impact.

## Shipped precedents (all numbers below derive from these)

- Sepulcher Elite 1010 vs Sexton base 1008: same level, hp ~0.9× (380/420), dmg +2, def +2, xp ~4× (3200/820), better gold band. THE elite pattern.
- Bounty cycle: tick-derived periods (`tick / kBountyCycleTicks`, 90 min), zero RNG — "random" timers must follow this (determinism law bans wall-clock/`random_device`).
- Announce: broadcast chat (`chatCh` 0, T-078 destroy precedent) for world-firsts.
- Gravemother telegraph (T-091): the only boss mechanic newer than the pattern.

## Option A — Mirror-1010 elites (three melee elites, one card each later)

| elite | map | base | L | hp | dmg | def | xp | timer |
|---|---|---|---|---|---|---|---|---|
| Old Maw | 2 fields | Gnoll 1005 | 7 | 145 | 19 | 12 | 1200 (~4×300) | 30 min |
| Red Widow | 4 mine | Widow 1006 | 9 | 200 | 24 | 14 | 1680 (~4×420) | 45 min |

- Timers: fixed per elite (deterministic), staggered phases so they don't coincide; first-kill broadcast once per reboot (session-scoped flag, bounty-board pattern).
- Cost per elite card: 1 mob row + 1 spawner + announce hook → epoch bump + soak + replay (content-sim change). Three small cards, not one big.
- Note: Cantor-as-1010-clone wastes a name — see B.

## Option B — Cantor Vex as bolt-caster (two melee + one signature)

- Old Maw + Red Widow as in A.
- Cantor Vex: Sexton base with boss-lite casting (boltRange 6, boltCd 52 — half Mother's rate, no telegraph, no curse; xp 5×4100 for the threat). Gives the crypt a ranged elite and reserves telegraphs for true bosses.
- Cost: same as A per card + caster-path test pins (T-070 bolt-test pattern). Slightly bigger diff (cast branch), same epoch discipline.

## Recommendation (non-binding)

A for Maw/Widow now (cheap, pattern-pure), B for Cantor (the name deserves a voice, and the caster path is already tested ground). Timers fixed-per-elite, never "random" in the RNG sense — GDD's "random" should be reworded to "rotating" when the cards land.
