# T-065 Wanted Board (session-scoped bounty) — DONE S18 (2026-09-05)

## Context

Era wanted-posters gave the town a per-session rumor about which quarry
matters. No persistence by design: if the server restarts, the wanted
sheet comes down with the world — the economy must breathe, not hoard.

## Scope

- `kWireKindBounty = 66` furniture; `spawnVendor` seeds one Wanted Board
  beside Marta (second spiral from spawn; skips furniture tiles).
- `kBountyQuarry` cycle (Gravemother 1500g → Gravecaller 400g → Widow 300g
  → Gnoll 250g), rotate every 90 world minutes; `World::bountyNow()`.
- Passive assign: ~0.5 Hz sweep per player checks ≤3 tiles of the board —
  standing near the board *is* the accept. Chat line posts the purse.
- Held mark kills the quarry exactly once → payout ON TOP of the natural
  gold band, sheet drains. Off-cycle marks don't pay (board moves on).

## Tests

- Seam-spawned board beside a fresh player: 160 standing ticks → mark
  held; cycle-0 quarry is the Gravemother; killed her → gold delta ==
  payout + natural band [400,650]; sheet drained; second same-mob kill
  stays inside the natural band (no silent re-pay).
