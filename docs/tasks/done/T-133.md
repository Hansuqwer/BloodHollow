# T-133 — Heartstone capture + crown channel (Phase S, 2b/4)

## Context

T-132 felled gates by breach. Behind the Inner Gate stands the Heartstone
(kind 76): presence-capture attunes it, then a registered attacker channels
the crown to take the castle (holder set, battle ends). Friday-Night leg 3
("ownership flips at least once") runs on this card.

## Scope

- `spawnHeartstone` on zone-6 load (staging by the Inner Gate; map-6
  constants land with PR #23): kind-76 furniture, hp 1 (capture is
  presence, never damage).
- Capture: per-tick in `World::tick`, only while battle active and the
  stone stands: registered attackers within 3 (same zone) vs all OTHER
  players within 3 — attackers present + no contest → `heartProgress_++
  (cap `kHeartCaptureTicks` = 1200, 60 s); contested or empty → hold
  (no decay, one-way MVP like gates). At cap: `heartAttuned_ = true` +
  chatCh-2 "the Heartstone drinks deep — it is attuned." (once).
- Crown: `/crown` → journaled `kCrown` → `World::crown(e)`: gates battle /
  attuned / registered / alive / same-zone ≤ 2 of the stone → channel
  `crownUntil = tick + 200` (10 s) + directed "you kneel before the
  Heartstone...". Per-tick `crownTick()`: break (quiet, directed line) on
  move (`walker.moving` or non-empty path), hit (`lastHurtTick` at/after
  channel start), death, battle end, or leaving radius; complete at
  deadline → `siegeHolder_ = crowner id`, battle ends, chatCh-2 "X takes
  the Weeping Crown!". Swings allowed mid-channel (era-fun); stillness is
  about feet, not steel.
- New `Entity.crownUntil` (-1 idle). Session-only, unpersisted, unhashed
  (like town/ek ruling: identity/fame-adjacent, no hash).
- NO epoch bump (zero draws; `t128.bwj` re-replay proof). NO wire change
  (crown shows as broadcast text; holder readout is a filed S3/GM item).

## Acceptance criteria

- Attunement needs 1200 uncontested attacker-ticks; any contesting
  presence freezes it; crowning needs attunement + channel intact for
  200 ticks; each break condition fires; holder + battle-end + broadcast
  exact; all journaled paths replay-exact.
