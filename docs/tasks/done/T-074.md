# T-074 — bad-leg death levers, one measured move (S25)

## Context
Handoff open thread #3: v5c takes heavy legs (142/134/116 deaths, legs
3/5/7). Levers: pack cap (`tools/bots/main.cpp:611`) and retreat/swarm
thresholds (`:789`).

## Bench (desk analysis, no compute)

Rerun-chain legs 3/5/7 bot logs (`logs/m2b_rerun_leg{3,5,7}_bots.log`):

| leg | deaths | killerByLvl | lastDeath | maxLevel |
|---|---|---|---|---|
| 3 | 142 | L3:64+78 (ALL) | (55,14) | L3/L2 |
| 5 | 134 | L3:66+68 (ALL) | (52,11) | L2/L1 |
| 7 | 116 | L3:52+64 (ALL) | (49,24)/(49,25) | L4/L3 |

Signature: **L3-ghoul treadmill**. Bots pin at ghouls_east/orchard edges,
die ~130×/leg, de-level to L1–L3, never escape (levelDrops 10–11). mend
128–132/leg (they heal through it and still lose). shops ~100 (respawn →
buy → walk back → die).

Mechanism (poverty trap): the pack cap `b.level >= 3 && pack >= 2` turns
OFF below L3 — exactly when the bots are weakest and need it most.
`pack` already counts only *aggressive* mobs (passive rats never pile on),
so the gate's stated reason (protect rat/bat starter diving) is half-stale:
rats are exempt by passivity; only bat packs change behavior.

## The one lever

Drop the `b.level >= 3` gate on the `pack >= 2` rule (pack counts OTHERS,
so ≥2 = 3+ clustered aggressive). Hypothesis: de-leveled bots stop diving
3+ ghoul packs; L1–L2 starter diving survives on passive rats + single
pulls (the `pack > 0 && lvl >= b.level - 1` singles rule still applies).
Retreat threshold untouched this round.

(`tools/bots/main.cpp` restored to v5c). Next pit: retreat 5→4, repeats,
