# T-139 — Pledge bands muster sworn war-hosts (Phase P, 2/3)

## Context

T-137 bands are parties (captain's living party, cap counts bands); T-138
rebased pledge identity (Entity.pledgeId, registry, g-sidecar). This card
replaces captain-id bands with pledge-id bands per the Phase-P queue.

## Scope

- `World::siegeRegister`: a sworn captain musters every living online
  member of the pledge as ONE band keyed by pledge id (`siegeBandPledges_`).
  A sworn caller whose pledge already enlisted musters missing members into
  the existing band (revive/relog path, no free slot needed); one pledge
  never takes two bands. Unaffiliated captains keep T-137 party shape.
  Desertion (leave/kick) never un-enlists: the muster is session law.
- `breach`/`crown`/attunement untouched (all key off `siegeAttackers_` ids).
- Journal unchanged (kSiegeReg carries captain id; replay re-derives the
  muster from restored pledge state). NO epoch bump (stays 26), no schema,
  no wire.

## Acceptance criteria

- 4 new doctest cases green; `t139.bwj` shows a 5-member single enlistment
  and replays mm=0; `t138.bwj` re-replays mm=0 (neutrality proof).

## Tests required

  muster, 8-band cap counts pledge bands, desertion law) wired into
