# T-056 PK law & chaos penalties — DONE S15 (2026-09-05)

## Context

GDD §5 is locked: karma −1000…+1000, red below 0, chaos = `−(300+20×deficit)`
per unlawful PK, chaotic death drops, gallows respawn, shop refusal, consent
duels. T-046 ships the columns and the moral ±15% split; the whip itself is
missing. Era rule: the gamble must be legible *before* the pull, so all
consequences print system-channel text.

## Scope

- **PK karma:** killPlayer(killer≠null, both players, victim karma ≥ 0, no
  active duel) ⇒ killer karma −=(300+20×max(0, killerLvl−victimLvl));
  clamp ±1000; ch-3 world line on deep-red transition (see T-057 band).
  Killing a chaotic player is free (gallows-market rule).
- **Whitening:** +1 karma per mob kill where `mob.level ≤ player.level`;
  +1 per 3 600 ticks logged in (era reading of GDD "+20/hour" — tick-domain
  only, no wall clock in sim). Both clamp +1000.
- **Chaotic death:** drop 1–6 random *non-equipped* inventory items (world
  rng; journal-visible via the kill), each equipped slot a 15% independent
  drop roll; dropped items are destroyed (fiction: the crowd picks the
  corpse — ground-item persistence is a later card, not this one);
  respawn at the **gallows pit** (town-edge anchor; walkable-search fallback
  to bindstone), not the temple square.
- **Vendor refusal:** Marta (buy AND junk-pawn) refuses karma<0 with a sneer
  on ch-2. Fence NPC is content-drop scope (T-065 area).
- **Duels (MVP-lite):** `/duel <name>` offers (20 s expiry); accepting =
  `/duel <proposer>` back within the window; while mutually engaged: kills
  carry no karma loss, no XP debt, no death drops; the duel ends on a kill,
  `/forfeit`, zone transfer, or party membership change of either side.
  Journal: `kDuel` (a=target id) + `kForfeit` Command kinds at the enum tail.
- Announce start/finish/forfeit on ch-3 ("A calls out B." / "the duel is
  done — X stands." / "X forfeits.").
