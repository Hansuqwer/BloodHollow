# T-131 — Siege scheduler + registration + holder slot (Phase S, 1/4)

## Context

MVP siege: weekly 90-min Weeping Castle battle (gates → Heartstone →
crown), taxes, holder buff, rehearsals. The castle MAP rides PR #23
(unmerged); H1's rehearsal stub rides PR #29 (unmerged, other lineage).
This card builds the zone-agnostic battle skeleton both later cards and
both PRs plug into — no map dependency, no pledge dependency.

## Scope

- Weekly window (pure tick math, game clock): Saturday 20:00–21:30 game
  time (90 min = 108000 ticks, same length as H1's rehearsal). Day index
  = floor(tick/288000) % 7 from the 08:00-anchored clock; Saturday = 6.
  `siegeWindowStart()`, `siegeWindowEnd()`, `inSiegeWindow()` — all
  deterministic, all pinned.
- Registration: war-band captains as PLAYER entity ids (resolved
  pre-journal, kDuel precedent), cap 8, dedup quiet, dead/unknown/mobs
  refused. Journaled `kSiegeReg` (a = captain id). PLEDGE SEAM (filed
  follow-up): bands upgrade to pledge ids when Phase P lands; the vector
  shape (`uint32_t` ids) is already pledge-compatible.
- Holder slot: `siegeHolder_` (captain id, 0 = unclaimed) + session
  `siegeAttackers_`. `siegeStart` (journaled `kSiegeStart`, GM
  `gm siege-start`): requires in-window + non-empty registry, else quiet;
  battle active until window end. Out-of-window rehearsals stay H1's
  `kSiegeNow` (PR #29) — clean division, no overlap.
- Session-scoped only (persistence of holder/taxes = S3). NO epoch bump
  (zero draws; proven by re-replaying `t128.bwj` mm=0). NO wire change.

## Acceptance criteria

- Window edges exact (start-1/start/end-1/end), weekly period 2,016,000;
  registry caps/dedups/refuses; holder defaults 0; battle only in-window
  with attackers; all journaled paths replay-exact.

## Tests required

- `tests/test_siege_sched.cpp`: window math (edges, periodicity, anchor),
  registration matrix, holder default, battle gating, kSiegeReg/kSiegeStart
  via applyWorldCommand.

## Out of scope

- Gates/Heartstone/crown (S2) · taxes/vault/buff + holder persist (S3) ·
  siege bots + M4 gate (S4) · castle map (PR #23) · pledge bands (Phase P)
  · H1 kSiegeNow (PR #29) · wire 237.
