## What shipped

- **Registrar post**: the pledge registrar (wireKind 72, reserved since
  T-094) now stands in Thornwall — first free tile spiralling from the
  town-square spawn point (deterministic, no RNG; one tile past Marta).
  Founding requires Chebyshev ≤ 3 proximity, the confessor pattern.
- **Founding gate**: level ≥ 10 **and** 10,000g toll; name 3–16 of
  `[A-Za-z0-9_-]`, unique forever. Founder becomes **Liege**.
- **Ranks**: Liege (3) / Bloodsworn (2) / Initiate (1). Bloodsworn and
  Liege invite (≤ 12 tiles, party radius); accepts join as Initiate;
  invites expire after 400 ticks; promote/demote are Liege-only; rank 3 is
  not grantable (Liege transfer is post-lite); kick is Liege-only; a
  Liege's leave **is** a disband.
- **Pledge chat**: `/p <msg>` routes to online members as directed lines
  (chatCh 255, one event per member — zero wire change); `/pledge who`
  answers a roster with online markers.
- **Persistence (schema v12, additive)**: `characters.pledge_id` +
  `characters.pledge_rank` columns; new `pledges` table (id, name, emblem,
  liege; members derived from the membership columns — single source of
  truth). Membership by **character name** (entities are transient);
  `e.pledgeId/pledgeRank` is the entity-side cache restored at login.
- **Journal**: new command kinds after `kRepent` (28–34; enum append-only,
  old journals replay with old kind numbers intact) and a **g-sidecar
  login line** `g tick idx pledgeId rank` (the T-053 k-line pattern —
  pre-v12 journals have no g-lines and parse unchanged). The c-line
  journal carries no strings: live creation passes the name via
  `Command::text`, replay synthesizes `pledge-<id>` (chat-only fidelity
  loss; hash-neutral — pledge state is deliberately **not** in worldHash).
- **Epoch 21 → 22**: the registrar is a world-composition change (a new
  permanent entity shifts every post-boot hash — `t120.bwj` replayed
  15/15 mismatches before the bump, exactly the T-112 spawn-semantics
  precedent). Bumped; old legs now refuse by guard (exit 4) instead of
  lying. Fresh leg of record: `logs/t122.bwj`.

calls flagged for review: member cap 20, 10k toll, emblem = `id % 10`
