# T-128 — Widow + Cantor + Gravemother uniques ×9 (H3 loot depth, 3–5/5 COMBINED)

## Context

T-127 established the unique pattern (table rows + `grantUniqueDrop`) for
Old Maw. The three remaining bosses are the identical mechanical shape
(3 ItemDefs + 3 rows + row-count/grant pins each). Splitting them into
T-128/T-129/T-130 would burn two extra epochs and two extra legs for zero
additional review value — the stream-shift event (new per-kill draws on
1013/1014/1009) is singular. Hence ONE combined card; numbers T-129/T-130
stay free. This completes the MVP 12-unique set (3 + 9).

## Scope

- 9 new ItemDefs (found, never stocked):
  - Red Widow (1013, mine nest): 2301 Widow's Needle (wpn 20, 900),
    2104 Silkwoven Shroud (arm 12, 850), 2302 Red Widow's Kiss (wpn 17, 800).
  - Cantor Vex (1014, crypt choir): 2303 Cantor's Quill (wpn 19, 1100),
    2105 Vigil Cope (arm 12, 1050), 2304 Vex Nail (wpn 16, 1000).
  - Gravemother (1009, L14 boss): 2401 Tithehook (wpn 28, 1800),
    2106 Sepulcher Plate (arm 16, 1700), 2402 Caulblade (wpn 24, 1600).

  weapon: 1/3/6/7/9 — Thorns/Ox/Mending on a blade would be mute text):
  - Widow @4%: Needle/Focus(6) "The Huntress Answers", Shroud/Mending(10)
    "Woven From Hunger", Kiss/Leech(3) "Drink, Dear".
  - Cantor @4%: Quill/Embers(7) "The Last Verse Burns", Cope/Vigil(8)
    "The Choir Keeps Watch", Nail/Whet(1) "Keen As Doctrine".
  - Gravemother @6% (boss judgment call: harder, fixed timer, L14):
    Tithehook/Greed(9) "The Mother Collects", Sepulcher/Ox(4) "Born Heavy",
    Caulblade/Leech(3) "First Blood, Again".
- `kJournalEpoch` 23 → 24 (new draws on 1013/1014/1009 kills). Fresh gate
