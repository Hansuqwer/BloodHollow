# T-117 — M3 party-crypt gate leg: 5-person mixed-kit party clears Crypt to Gravemother

## Context

The roadmap's M3 exit criterion — "a 5-person party clears the Crypt to the boss" — has never been run as a formal gate. Phase 3 shipped parties (cap 8, XP share 12-tile radius, +12%/sharer, heals 100% weight), full Cultist kit v2 (Mend/Bless/Ironskin/Chorus/Mass Mend/Haste/Purify), Gravemother L14 with telegraphed 60t wind-up radius-2 slam + bolt-mirror Blood Curse, and the full portal chain Thornwall (mapId 1) → Thornwall Crypt (mapId 3, portal crypt_hatch 10,10 → 24,30) → Drowned Crypt Depths (mapId 5, portal depths_stairs_down 44,6 → 3,30 / up 2,30 → 44,6). The boss presides at gravemother_font (21,2) in map 5, surrounded by 8 Sepulcher Elite camps and supporting spawns (gravecaller, sexton). No formal measurement exists of whether 5 bots (mixed kits, Cultist heals matter) can reach the boss, survive the slam, and kill her. This card runs that measurement.
