# T-127 — Old Maw uniques ×3 (H3 loot depth, 2/5)

## Context

Elites exist (T-101..T-103) with first-blood announce; affix v2 (T-126)
gives fixed affix ids to reference. MVP wants ~12 boss/named uniques;
this card ships Old Maw's (1012, fields pit) three, establishing the
unique-drop pattern T-128..T-130 copy.

## Scope

- `shared/content/items.h`: 3 new ItemDefs — 2201 Mawsplitter (weapon,
  dmg 22, value 600), 2103 Gullet Plate (armor, def 13, value 700),
  2202 Mawfang Shiv (weapon, dmg 15, value 450). Uniques are NOT vendor
  stock (found, not bought); client renders placeholder fallback (art
  follow-up, T-ART-05 covers new ids when sheets land).
- `shared/content/items.h`: `UniqueDropDef {mobId, itemId, affix,
  chancePct, title}` + `kUniqueDrops[]` (3 rows for 1012, 4% each,
  independent rolls):
  - Mawsplitter, fixed of Embers (7) — "Tooth of the Pit".
  - Gullet Plate, fixed of Thorns (5) — "The Maw That Keeps".
  - Mawfang Shiv, fixed of Greed (9) — "Tithetaker".
- `server/src/world.cpp` `killMob`: per-row roll (night rides at +25%
  like every other drop, T-062 law) → `grantUniqueDrop` (public for
  tests): item + fixed affix into inv (cap 32 respected), world broadcast
  on chatCh 2 (`"<killer> claims <name>, <title>!"`), era-loud by design.
- `kJournalEpoch` 22 → 23: the per-row `range(1,100)` draws on every Old
  Maw kill shift downstream draws in old journals touching 1012. Fresh
  gate leg `logs/t127.bwj`. COLLISION FLAG: arena PR #23's title claims
  epoch 23; T-115 double-19 precedent rules — if #23 merges first holding
  23, the next in-tree card re-bumps.

## Acceptance criteria

- Old Maw kills can yield 0–3 uniques at ~4%/row; grants carry the fixed
  affix (never rolled); broadcast fires per grant; inv-full drops nothing
  (no partial state).
- Battery green + `t127.bwj` mm=0 + guard refuses t126 (22 vs 23) exit 4.

## Tests required

- `tests/test_uniques.cpp` (new TU, grows with T-128..T-130): table shape
  (3 rows for 1012, affixes ≤ kAffixCount, items resolve in kItems, titles
  non-empty), `grantUniqueDrop` direct (item + fixed affix + broadcast
  event + inv-cap refusal), no-epoch-shape assertion is out (guard is
  runtime).

## Out of scope

- Widow/Cantor/Gravemother rows (T-128..T-130) · drop-rate retuning ·
  vendor/fence sale of uniques · art sheets · wire change (stays 237).
