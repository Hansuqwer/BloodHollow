# T-130 — EK ledger + L19 town oath (H4 night war, 2–3/3)

## Context

MVP demands the town-of-19 war + EK board (GDD §1: swear at 19; killing a
sworn enemy grants EK fame instead of chaos). No town identity exists;
PK law (T-056) stains every unlawful kill. This card adds the oath, the
persisted town/EK columns, and the war-kill rule. (Numbering note: T-129
was taken by Blood Moon after T-128 combined the trio — this number was
free, not the Cantor card.)

## Scope

- `shared/content/towns.h` (new): 0 unsworn / 1 Thornwall (Ashen Compact)
  / 2 Marrowgate (Pale Synod); `kTownOathLevel` 19; names + factions.
- `Entity.townId` (u8) + `Entity.ek` (u32). `World::oath(e, town)`:
  player/alive/unsworn/L19+/valid-town gates (Helbreath rule, one oath,
  no respec in MVP); chatCh-2 town-crier broadcast; journaled via
  `Command::kOath` (`/oath thornwall|ashen|marrowgate|synod`, kit-parse
  shape; unknown names stay spoken).
- `killPlayer` war law: killer + victim both sworn, different towns →
  `killer.ek++` + fame broadcast, and the unlawful block (karma stain,
  red-hands line, guard wanted) is SKIPPED (GDD: EK instead of chaos).
  Chaotic-victim crowd-pick drops still run (victim-state based). Duels
  return earlier — consensual duels never mint EK.
- Persist (schema v12, additive): `town_id` + `ek` columns (default 0);
  `CharacterRow` + SELECT + `saveProgress` params; live login + logout
  apply. Journal: `w tick idx town ek` SIDECAR (kit `k`-line precedent —
  the v3 l-line stays untouched; missing sidecar replays as 0,0).
- `World::ekBoard(n)` (sorted desc, session board) + `gm ek` GM readout
  (directed 255-lines, top-5; empty board says so). Site DB page is
  Phase O.
- NO epoch bump (zero new RNG draws anywhere; proven by re-replaying
  `t128.bwj` mm=0). NO wire change.

## Acceptance criteria

- Oath gates hold (L18/invalid/re-oath/dead refused); war kills mint EK
  with no stain; same-town/neutral kills stain as before; duels mint
  nothing; town+EK survive logout/login; sidecar replays exact.

  (T-118 Db-test shape).

## Out of scope

  guard-faction behavior changes beyond the wanted skip · wire 237.
