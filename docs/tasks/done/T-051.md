# T-051 party XP share — DONE S13 (2026-09-05)

## Context

The era reason to group. From the S12 campaign legs: solo pacing plateaus at
L6 (~30 min/level post-L5); the M2b-final L1→8 single-sitting gate needs XP
throughput that scales with cooperation, without turning solo play punitive.

## Delivered (in `World::killMob`)

- Sharer set: alive, same zone, same party, within `kPartyXpRadius = 12`
  tiles (Chebyshev) **of the kill position** (captured pre-despawn).
- Payout per sharer: `xp * (100 + 12*(n-1)) / 100 / n`
  (`kPartyXpBonusPct = 12`), routed through the existing `awardXp` so the
  karma +15% bearer still applies per-member and level-ups ding normally.
- 0/1-sharer falls back to the untouched solo path (full pool to killer).
- **Loot and gold stay with the killer** — era rule; party raw power is XP,
  itemization remains personal and tradable.
- Each share emits a ch-2 system line "party share: N xp." (visible in the
  party-shared run's chat and journal).

## Design knobs (next tune points if T-034b or M2b-final say so)

- `kPartyXpBonusPct` per extra sharer (12).
- `kPartyXpRadius` around the kill (12).
- Deaths/zone gates already applied; no cross-zone splash.
