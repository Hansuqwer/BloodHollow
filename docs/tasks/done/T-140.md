# T-140 — Pledge vault: tax-only pool, deposit-only MVP (Phase P, 3/3)

## Context

Pledge-lite ships vault-tax-only per the MVP cut (T-122 OUT, T-134 pool).
This card closes Phase P: the pledge vault accrues from the siege tax drip
(sworn holders) + voluntary tithe. No withdrawal economy (MVP rule).

## Scope

- `World::Pledge::vault` (outside worldHash, T-122 social-state law) +
  `pledgeTithe` (member, amount>0, purse covers; directed receipt line) +
  `pledgeVaultReadout` (`/pledge vault`, directed, unjournaled).
- Drip routing (kill path): seated holder whose name rides the pledge
  registry feeds the pledge vault; unsworn holders keep the castle pool.
  Holder need not be online (name-keyed).
- `/pledge tithe <N>` (digits-only, journaled kind **41**, c.a = amount).
- Schema v13→**v14** (`pledges.vault_gold`); `PledgeRec::vault`; load/upsert
  carry it; shell flush + boot load carry it. No epoch bump (stays 26),
  no wire change.
- Pledge bots: liege tithes 500 + reads vault at ceremony end (leg fodder).
- Disband burns the vault with the row (documented; MVP has no payout).
