# T-136 — Rehearsal mode + siege bot profile (Phase S, 4a/4)

## Context

S1–S3 + map are shippable but unexercised live: the battle only runs in
the Saturday window (26 h wall away) and no bot speaks siege verbs. This
card adds an explicit rehearsal posture (flag-gated, journal-guarded) and
attacker bots that march, register, breach, attune, and crown — the
Friday-Night leg-3 shape at drill scale. M4 metrics (40 bots, p99, 3/3
flips) are T-137 on top of this card.

## Scope

- Server `--siege-rehearsal`: `World::setRehearsal` opens the window
  unconditionally (loud boot printf, never default). Journal `v` line
  carries a `rehearsal` marker; replay refuses cross-mode journals
  (exit 4, epoch-guard shape). Default path byte-identical → NO epoch
  bump (proven by re-replaying `t135.bwj` mm=0).
- Bot profile `siege` (attackers; defenders are T-137): staging tiles
  hardcoded from the generator (gates (23,10)/(26,10), stone (29,10),
  castle_road (21,14) — tmj-verified walkable, commented with provenance;
  PR #23's real map updates them). Choreography: march → portal →
  `/siege-reg` → bot0 `gm siege-start` → breach ×40 per gate (2 s
  cadence) → stone presence → `/crown` loop; death resets to march;
  fighter targeting extended to siege (yard hounds die en route).
  Telemetry: regs/breaches/crowns SENT (verbs, not outcomes).
- Drill leg `tools/t136_siege_drill.sh`: rehearsal server, sqlite top-up
  (L12 + Pit Blade + Hide Armor + vials, server-down, disclosed like
  m3_topup), 6 siege bots × ~360 s; asserts bands ≥ 1, battle joined,
  ≥1 gate down, attuned, crowned (holder ≠ 0); replay mm=0.
- TU: rehearsal window pins in `test_siege_sched.cpp`.

## Acceptance criteria (closed scope — live crown moved to T-137, see devlog)

- Flag off: everything byte-identical (t135 replays mm=0). Flag on:
  battle runs at tick 500. Drill flips through ATTUNEMENT live (bands,
  battle, both gates, attuned) and the drill journal replays mm=0.
  Cross-mode replays refuse exit 4. Crown channel/holder/battle-end
  proven at unit level (T-133); the live flip is T-137 with defenders.
