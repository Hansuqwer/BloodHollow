# 0065 — Eighteen pelts and a proof (T-096)

T-096 ran the rite the way a player lives it — same names, same bank, three legs — instead of the way the harness usually measures (fresh everything, one leg).

## What the three legs say

- **Banking is real:** 8 → 18 pelts, gold tripling, L3 → L4, all through 50-death legs. Neutral drops survive death; the DB discipline (same file + same prefix, no sqlite fiddling) resumes cleanly with replays green every time. Future progression demos should copy this recipe.
- **The lane is proven:** three blessed pilgrims walked up, paid, and left grafted, 3-for-3, first-try mercy. Every refusal branch T-086 mapped (skill, gold, parts, proximity, order) now has a witnessed accept on the other side. `anvilTries` lifetime: 0 across ~15 legs → 3 in one afternoon.
- **Skill does not bank:** the schema has no skill column, so every login starts the sword over. This sharpens T-093/B considerably — multi-leg progression covers pelts and gold, but skill 20 demands either one long session or the bless lane. If the director wants soak-visible grafting without retuning, bless-seeded proof legs (this card's leg C) are the honest vehicle, not economy edits.

## Judgment calls

- Bless-seeding is measurement scaffolding, not cheating: the grants are journaled b-lines, replayed, and disclosed; they isolate the gate chain from the income curve, which is exactly what an acceptance proof should do.
- The post-leg aura-0 read is left open deliberately: chasing it would have meant a fourth leg for a question nobody asked (the card asked whether the lane works — it does). One-line follow-up available: single pilgrim, bless, graft, kill once via debug, read the blade.
