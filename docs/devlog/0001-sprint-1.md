# Devlog 0001 — Sprint 1 complete: "Empty World" walks *(2026-09-04)*

Sprint 1 (pulled forward from the Sep 7 plan) is done. The M0 milestone
criteria are met: an isometric world renders, a hero walks it with click-to-move
and 8-direction animation, the map pipeline is end-to-end (generator -> Tiled
JSON -> binary .bhmap -> renderer), and the test suite is green with 316k
assertions.

## What got built

- **Build system**: CMake presets for linux-gcc/clang + macOS-arm64/x86_64,
  vendored doctest/json as SYSTEM includes, raylib 5.5 pinned via FetchContent
  SHA-256, `-Werror` on all our targets only.
- **BloodEngine v0**: iso transforms (nearest-center click picking), diamond +
  prism tile drawing, two-pass painter's sort, camera rig (follow / MMB pan /
  stepped zoom), day/night tint LUT (dawn-dusk warm band, 140-alpha night),
  uniform-grid animation atlas + procedural placeholder hero (zero binary art
  in repo).
- **shared/sim v0**: xoshiro256** (platform-deterministic; Lemire unbiased
  `range`), fixed-cost 8-dir grid + octile heuristic, A* with corner-cut
  prevention and deterministic tie-breaks.
- **Format v0**: `.bhmap` — RLE layers, blocker bitfield, spawner/portal
  tables, FNV-1a-64 checksum with tamper detection.
- **Tools**: `bh_mapconv` (Tiled JSON -> bhmap + `--validate` gate),
  `tools/mapgen/make_thornwall.py` (deterministic placeholder map; CI diffs a
  regeneration against the committed file so hand edits route through code).
- **Client**: `bh_client` walks Thornwall offline at the era-authentic
  4 ticks/tile pace; HUD shows tick/pos/hour; debug keys F3/F4/H/N/Z/Space.
  `--screenshot PREFIX` runs a scripted 200-frame demo (walk order + night
  shift + captures) for CI/demo automation.

## Verification

- `ctest`: 13 cases, 316,066 assertions, all pass. Includes the property test:
  1000 seeded random pathfinding queries on a 64x64 / 20%-blocked grid equal a
  Dijkstra reference exactly, with per-step legality re-checked.
- Headless scripted run under Xvfb produced the screenshots above from the
  real client build.
- Map regenerated byte-identically from its generator (determinism gate).

## Lessons recorded

1. raylib 2D culls "screen-clockwise" triangle windings — diamonds vanished,
   prisms partially showed. Probe program proved it; winding order fixed and
   documented in `render/iso.cpp`. **raylib 2D primitives are winding-sensitive.**
2. raylib `TakeScreenshot` ignores directory prefixes (saves to its basePath).
3. 20% blocked 64x64 grids fragment ~35% of pairs — property-test thresholds
   must reflect that, not vibes.
4. doctest forbids `&&`/`||` inside assertion macros (expression decomposition);
   hoist to named bools first.
5. `pip install cmake` on this sandbox gives cmake 4.x — vendoring single
   headers avoided all old-cmake-minimum policy pain from FetchContent deps.
